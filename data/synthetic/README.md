# Synthetic data

Everything in this folder is generated by `scripts/make_synthetic_data.py` (seed 20261011) and
`src/trident/ingest/synthetic.py`. Every record carries `is_synthetic: true` and is excluded
from all reported evaluation metrics.

| File | Rows | Purpose |
|---|---|---|
| synthetic_news.jsonl | 3000 | Training augmentation for the event and sentiment models (capped share, reweighted; eq. D3/D4) |
| market_news.jsonl | 940 | Known-answer test: dated events that drive `data/market/prices_synthetic.csv` |

Hard cases are injected with probability 0.35 (negation, sarcasm, multi-entity, delta-phrase,
retrospective, rumor-then-denial). Severity 7-10 is oversampled to 25% (eq. D2). Arrival times
follow a Hawkes process (eq. D1) when `burst=True`.

## LLM generator prompt (`LLMGenerator`)

```
You write realistic financial text for model testing.
Return JSON only: {{"text": str, "label_event": str, "label_polarity": "pos"|"neg"|"neu", "intended_severity": int}}
Entity: {name} ({ticker}), sector {sector}
Event class: {event_class}   Polarity: {polarity}   Severity (1-10): {severity}
Register: {register}   # newswire | tweet | 8-K excerpt
Constraints: under 35 words; no real journalist names; plausible invented figures;
if register=tweet use informal style, may include ${ticker}. Hard case: {hard_case}
```
